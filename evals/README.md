- unsupported knowledge near-match must not be presented as an answer
- operational dates/times/locations must be grounded in tool output
- ambiguous item reference must not trigger a return proposal
- natural-language return reason maps to a controlled category
- return eligibility must not be claimed before Commerce responds
- the agent proposes but cannot directly execute consequential actions
